# 출력 형식

작업 완료 후 반드시 아래 형식으로 요약한다.

## 1. 생성한 파일 목록
- 파일 경로 나열

## 2. 각 파일 역할 요약
- Controller: API 진입점
- Service: 트랜잭션 및 비즈니스 흐름
- Repository: JPA 조회/저장
- Entity: 도메인 모델
- DTO: 요청/응답 모델
- Mapper: Entity ↔ DTO 변환

## 3. 아직 사람이 채워야 할 부분
- 엔티티 필드 / 연관관계 / 권한 정책 / 상태 정책 / 삭제 정책 /
  목록 조회 조건 / ErrorCode 세부 항목 / 테스트 코드

## 4. 다음 작업 추천
- 기존 도메인과 비교 / 빌드 실행 / API 명세 확인 /
  Service 비즈니스 정책 확정 / 테스트 생성
