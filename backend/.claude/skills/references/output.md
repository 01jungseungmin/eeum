# 단계별 개발 출력 형식

각 Gate 완료 시 현재 단계와 검증 결과를 짧게 공유하고, 전체 작업 완료 후 아래 형식으로 요약한다.

## 1. 범위와 정책 결정
- 완성 구현 / 순수 스캐폴딩 구분
- 구현 범위와 제외 범위
- 확정한 API·권한·공개·상태·삭제·동시성 정책
- 사용자 승인·보류 항목

## 2. 단계별 변경 파일
- Domain·Persistence
- Application·Transaction
- API·DTO
- 교차 도메인·운영 DDL
- 테스트

각 그룹에 파일 경로와 역할을 함께 적는다.

## 3. Gate 검증 결과
- Gate 1 계약·정책
- Gate 2 영속성·아키텍처·컴파일
- Gate 3 트랜잭션·보안·동시성
- Gate 4 API 계약·Validation
- Gate 5 교차 도메인·운영 정합성
- Gate 6 테스트·빌드
- Gate 7 최종 전체 리뷰

각 Gate를 `통과 / 실패 / 미실행 / 사용자 보류`로 표시하고 실행한 명령과 근거를 적는다.

## 4. 남은 작업과 위험
- 아직 결정되지 않은 정책
- 실행하지 못한 테스트와 이유
- 외부 계약·운영 환경에서 추가 확인할 항목
- 다음 단계 또는 배포 전 필수 작업
