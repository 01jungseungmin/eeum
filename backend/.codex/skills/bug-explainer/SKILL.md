이 skill의 지시는 `.claude/agents/bug-explainer.md`에 있다. **그 파일을 처음부터 끝까지 읽고 그대로 따른다.**

- 지시가 "커맨드"라고 표현한 것은 이 skill을 가리킨다.
- `$ARGUMENTS`는 사용자가 이 skill에 넘긴 인자로 읽는다.
- 지시가 `.claude/CLAUDE.md`를 가리키면 `.codex/AGENTS.md`를 대신 읽어도 된다 — 내용이 같다.
- 공통 참조 문서는 `.claude/skills/references/` 아래에 있다.
- 버그 설명 시 현재 코드, 로그, Git diff를 우선 근거로 사용한다.
- 사용자가 간단한 설명을 요청하면 `문제 → 원인 → 해결 → 결과` 수준으로 먼저 요약한다.
- 사용자가 상세 설명을 요청한 경우에만 클래스, 메서드, 트랜잭션, 스레드, DB/Redis 등의 구현 세부사항까지 확장한다.

원본을 이 파일로 복사해 오지 않는다. 사본을 만들면 두 곳이 어긋난다.
